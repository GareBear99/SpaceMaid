# SpaceMaid



SpaceMaid is a spatial effects plugin built for depth, width, ambience, and mix space.

It is designed to help producers create a sense of dimension quickly, whether for subtle room enhancement or more stylized atmospheric processing.

## What SpaceMaid Does

SpaceMaid focuses on the spatial side of mixing:

- ambience
- depth
- width
- movement
- atmosphere
- space around sounds

It is intended to be useful both as a practical mix tool and as a creative effect.

## Intended Use Cases

- adding depth to vocals and instruments
- creating ambience
- widening and opening up elements
- building atmosphere
- placing sounds in a mix more naturally
- creative spatial design

## Core Design Goals

- fast results
- intuitive control
- practical daily workflow
- creative flexibility
- useful from subtle to obvious settings

## Position in the Maid Audio Lineup

SpaceMaid is part of the Maid Audio suite:

- **FreeEQ8** — parametric EQ - https://github.com/GareBear99/FreeEQ8
- **BassMaid** — low-end enhancement - https://github.com/GareBear99/BassMaid
- **GlueMaid** — glue and cohesion - https://github.com/GareBear99/GlueMaid
- **SpaceMaid** — depth, width, and ambience - https://github.com/GareBear99/SpaceMaid

Together, these plugins form a lightweight mixing toolkit.

## Plugin Format

SpaceMaid is built with JUCE for modern plugin workflows.

Target formats include:

- VST3
- AU

## Status

SpaceMaid is under active development and refinement.

Current focus includes:

- DSP tuning
- UI polish
- workflow improvement
- release hardening

SpaceMaid is planned as an affordable paid plugin and as part of the Maid Audio bundle.
